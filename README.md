# 考試專用倒數計時器

給考場／教室投影用的全螢幕倒數計時器。

## 功能

- **超大倒數數字**：遠距離也看得清楚，支援超過 60 分鐘（例如 `90:00`）
- **兩種設定方式**：輸入考試時長（分鐘），或直接指定結束時刻
- **顏色警示**：剩 10 分鐘轉黃、剩 3 分鐘轉紅、結束時閃爍並播放提示音
- **可編輯科目名稱**：點擊標題即可修改，重新整理後仍會保留
- **頂部現在時間**：方便對照考場時鐘
- **隱藏設定列 / 全螢幕**：投影時畫面更乾淨
- **快捷鍵**：`空白鍵` 開始／暫停、`R` 重設、`F` 全螢幕
