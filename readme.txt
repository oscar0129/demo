============================================================
考試專用倒數計時器 ─ 功能介紹
============================================================

這是一個為考場大螢幕設計的單頁倒數計時器，免安裝、免登入，
打開網頁就能用；另外提供可選的「中文 AI 語音廣播」，讓鐘聲
之外還能自動播報考試提醒。

線上使用：
https://oscar0129-exam-timer.static.hf.space/

更新日期：2026-11-16


------------------------------------------------------------
一、核心計時功能
------------------------------------------------------------

‧ 大型倒數顯示：以 MM:SS 呈現，超過 60 分鐘也能顯示
  （例如 90:00）。

‧ 以結束時間戳計算：切換分頁、電腦休眠後回來，剩餘時間
  仍正確，不會累積誤差。

‧ 開始 / 暫停 / 重設：暫停會保留當下剩餘時間，可隨時繼續。

‧ 歸零提示：時間到自動播放三響鐘聲，並顯示
  「考試時間結束，請停止作答！」。


------------------------------------------------------------
二、兩種設定時間方式
------------------------------------------------------------

1. 輸入考試時長
   輸入 1～300 分鐘，按「套用」。

2. 指定結束時刻
   選擇結束時間，系統自動換算剩餘時間。

設定後會同步回分鐘欄位，方便微調。


------------------------------------------------------------
三、視覺與狀態提示
------------------------------------------------------------

‧ 剩 10 分鐘：倒數轉為琥珀黃，狀態列提醒「請把握時間」。

‧ 剩 3 分鐘：倒數轉為警示紅，提醒檢查答案卡與姓名。

‧ 時間歸零：紅色閃爍狀態。

‧ 頂部即時顯示「現在時間」。

‧ 深色高對比版面，字體隨螢幕大小自動縮放，適合教室大電視。


------------------------------------------------------------
四、AI 語音廣播（新功能）
------------------------------------------------------------

【啟用方式】

1. 點頂部「🎙️ 啟用 AI 語音廣播（需下載模型）」。
2. 按鈕會即時顯示「⏳ 載入語音模型中 45%...」。
3. 完成後變成綠色「✅ AI 語音廣播已就緒」。
4. 可按旁邊的「🔊 試聽廣播」測試喇叭音量。

【自動廣播時機】

‧ 開始計時：
  考試開始，請同學開始作答。

‧ 剩 10 分鐘：
  提醒各位同學，距離考試結束還有十分鐘，請把握時間。

‧ 剩 3 分鐘：
  距離考試結束還有三分鐘，請檢查答案卡與姓名座號。

‧ 歸零：
  先響完原本鐘聲，再播「考試時間結束，請停止作答，
  並將考卷與答案卡放在桌上。」

【設計細節】

‧ 每個時間點只會廣播一次，不會重複播放。

‧ 按「重設」或重新設定時間後，下一場考試會重新啟用廣播。

‧ 只有「模型已就緒」且「結束提示音：開」時才會自動廣播。

‧ 未啟用 AI 模型也沒關係，時間到仍會響原本的鐘聲。

‧ 語音在瀏覽器本機生成，不會上傳任何聲音或文字。

‧ 首次啟用需下載約 38 MB 模型，之後由瀏覽器快取。


------------------------------------------------------------
五、操作便利性
------------------------------------------------------------

‧ 科目名稱可直接點擊修改，自動記住，並同步更新分頁標題。

‧ 隱藏設定列：考試開始後可收起下方設定區，畫面更乾淨。

‧ 全螢幕模式：一鍵切換，適合投影或大電視。

‧ 結束提示音開關：可依考場需求關閉鐘聲與廣播。

‧ 快捷鍵：
    空白鍵：開始 / 暫停
    R：重設
    F：全螢幕

‧ 自動記憶：科目名稱、考試時長、提示音開關會存在瀏覽器
  localStorage。


------------------------------------------------------------
六、考前建議流程
------------------------------------------------------------

1. 開啟網頁，設定考試時長或結束時間。
2. 修改上方科目名稱（例如「第二節：英文科」）。
3. 按「啟用 AI 語音廣播」，等綠色就緒。
4. 按「試聽廣播」確認大電視音量。
5. 按「開始計時」，之後的 10 分鐘、3 分鐘與結束提醒
   都會自動播報。


------------------------------------------------------------
技術摘要
------------------------------------------------------------

‧ 純 HTML / CSS / JavaScript，無後端。

‧ 語音使用 Transformers.js 搭配 BricksDisplay/vits-cmn
  中文 VITS 模型（量化版約 38 MB）。

‧ 以 Web Audio API 播放模型輸出的音訊。

‧ 推論全部在瀏覽器 WASM 完成，不需伺服器。
